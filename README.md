# CHRONOS 時序之戰

獨立開發中的 5–10 人史詩奇幻陣營推理派對遊戲。

- 目前版本：0.0.2
- 開發基礎：Avalon-game v0.1.49 的已驗證遊戲流程原型
- 陣營：時間守護者、命運反抗軍
- 角色：時序之神、命運觀測者、時間騎士、命運刺客、虛無之主、隱時者、孤時旅者、時間掠奪者
- 本階段：完成角色名稱、陣營名稱、遊戲規則說明與時間節點用語轉換；保留原有發牌、身份視野、組隊、表決、秘密任務與勝負判定邏輯。

## 後續工作

- 以 CHRONOS 原創角色美術替換目前暫用的角色圖片。
- 完成統一角色美術風格、卡牌、首頁與遊戲介面。
- 後續再擴充自由角色配置與預設配置，並驗證所有角色組合。

> 本專案與原 Avalon-game 儲存庫分開維護。本階段沿用原型素材僅供開發測試，正式公開前須替換為 CHRONOS 原創美術與品牌素材。
