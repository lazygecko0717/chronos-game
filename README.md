# CHRONOS 時序之戰

版本：v0.2.0

[開始遊戲](https://lazygecko0717.github.io/chronos-game/)

5–10 人同一裝置輪流操作的史詩奇幻陣營推理遊戲。時間守護者修復五個時間節點，命運反抗軍挑戰既定命運。

## 功能
- 11 種角色、預設與自由配置
- 秘密身份、組隊表決、匿名任務、最終命運裁決
- 原創世界觀、角色美術、卡牌、首頁及時鐘戰場
- 可關閉的合成音效、PWA 主畫面圖示及離線素材快取
